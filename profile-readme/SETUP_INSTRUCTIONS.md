# Setup Instructions

## 1. Create the special repository
GitHub only shows a profile README from a repo with the **exact same name as your username**.

1. Go to https://github.com/new
2. Repository name: `fang1177`
3. Visibility: **Public** (required)
4. Check "Add a README file", then create it.

## 2. Add these files
Commit these files into that repo, preserving folder structure:

```
fang1177/
├── README.md
├── scripts/
│   └── update-projects.js
└── .github/
    └── workflows/
        ├── update-readme.yml
        └── snake.yml
```

From your computer (git installed):
```bash
git clone https://github.com/fang1177/fang1177.git
cd fang1177
# copy in README.md, scripts/, .github/
git add .
git commit -m "Set up premium dynamic profile"
git push
```

## 3. Enable Actions write permissions
Repo → **Settings → Actions → General** → under "Workflow permissions" choose **"Read and write permissions"** → Save.

This lets both workflows commit back to your repo (project list + snake animation).

## 4. Trigger both workflows once (to see results immediately)
Repo → **Actions** tab:
- Run **"Update Profile README"** manually first
- Run **"Generate Snake"** manually — this creates an `output` branch with the animated SVG. The README already points to it, so once it runs, the snake will appear automatically.

After the first manual run, both run automatically:
- On every push to this repo
- Daily on a schedule (so they also reflect activity across your *other* repos)

## 7. Don't hand-edit
The block between `<!--START_AUTO_PROJECTS-->` and `<!--END_AUTO_PROJECTS-->` is regenerated by the Action — any manual edits there get overwritten on the next run. Everything else is safe to edit freely.
