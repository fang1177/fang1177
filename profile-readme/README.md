## 🧠 About Me

I'm a full-stack developer and AI/ML engineer who builds complete, production-shaped products — not just notebooks or prototypes. My focus sits at the intersection of **web engineering** and **applied AI**: taking a model from a Jupyter notebook to a real interface someone can actually use.

- 🔭 Currently building end-to-end AI-powered platforms (healthcare, genomics, sentiment analysis, community platforms)
- 🤖 Deep interest in **GenAI / LLMs**, **NLP**, and **Explainable AI (XAI)** — making models people can trust, not just black boxes
- ⚡ I care about the full pipeline: data → model → API → UI → deployment
- 🌱 Actively expanding into more advanced ML systems and scalable architectures
